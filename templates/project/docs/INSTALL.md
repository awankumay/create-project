# Platform setup

Use PHP 8.4+, Composer 2, Git, Flutter stable with Dart 3.10+. Desktop target Windows requires Windows and Visual Studio with Desktop development with C++; VS Code is an editor and does not replace this toolchain. Android requires Android SDK, accepted licenses and a configured device/emulator.

Run `flutter doctor -v` before installation. Windows users may need Developer Mode for plugin symlinks. Use Git Bash for the URL installer, and ensure Windows PHP, Composer and Flutter commands are available on PATH. Build and test each target on its supported host OS.

The client uses Drift code generation. Its .g.dart file is created during installation; if skipped, run build_runner before analyze/test/build. Native platform runner files are generated by the installed Flutter SDK; the installer does not copy a stale Android/Windows runner from another app.

The installer adds `<uses-permission android:name="android.permission.INTERNET"/>` to the Android main manifest. Use an HTTPS API origin; debug manifest permits local development HTTP, release does not. Change com.example application IDs and implement signing before distribution.

Filament assets are published using `php artisan filament:assets`. This starter uses Filament's standard panel assets; a separate frontend/Vite build is not needed for that panel. The official Laravel skeleton still includes its normal frontend files for later customization.
